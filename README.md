# PhrasePal

Offline travel phrasebook. Bundled phrases and on-device audio. No microphone, no location, no account.

Package: `com.PhrasePalMNG.PhrasePal`

Remote IAP config: `https://api2.blwsmartware.net/N237.json`  
If `disable=1`, Google Play coin packs are hidden. The shop (stars for themes, skins, language packs, features) stays.

Products: `pp_pack_1`…`pp_pack_10` (consumable stars), `pp_remove_ads` (one-time).
